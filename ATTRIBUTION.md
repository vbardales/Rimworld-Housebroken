# Attribution

No third-party code is reused in this mod: everything here is written from scratch.

The starting idea comes from **Sentience Catalyst Filth Rate Reducer** by FlyingSloth
(https://steamcommunity.com/sharedfiles/filedetails/?id=3525790312), which reduces the filth
of animals carrying the sentience catalyst. Housebroken takes the same principle but changes
the criterion: training and trainability, of which the catalyst is only a special case
(`TrainableUtility.GetTrainability` raises trainability by one step when the hediff is
present). No file from that mod was read or copied.

The mod depends on Harmony (brrainz.harmony, MIT) and RimWorld 1.6.
