# Attribution

Aucun code tiers n'est repris dans ce mod : tout est ecrit ici.

L'idee de depart vient de **Sentience Catalyst Filth Rate Reducer** de FlyingSloth
(https://steamcommunity.com/sharedfiles/filedetails/?id=3525790312), qui reduit la salete
des animaux porteurs du catalyseur de sentience. Housebroken reprend le principe mais
change le critere : le dressage et la dressabilite, dont le catalyseur n'est qu'un cas
particulier (`TrainableUtility.GetTrainability` fait monter la dressabilite d'un cran
quand le hediff est present). Aucun fichier de ce mod n'a ete lu ni copie.

Le mod depend de Harmony (brrainz.harmony, MIT) et de RimWorld 1.6.
